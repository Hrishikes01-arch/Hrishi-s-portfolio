## 3. Blinkit Sales Dashboard

### Project Overview
This project analyzes Blinkit grocery sales and outlet performance using Power BI.

### Objectives
- Monitor Total Sales, Average Sales, Number of Items, and Average Ratings.
- Compare sales across item types and fat-content categories.
- Explore outlet performance using interactive slicers.

### Dashboard Features
- KPI cards
- Product and outlet analysis
- Interactive slicers
- Detailed sales table

### Tools Used
- Power BI Desktop
- BlinkIT Grocery Data

### Repository Contents
- `BLINKIT SALES DASHBOARD(1).pbix` — Power BI dashboard.
